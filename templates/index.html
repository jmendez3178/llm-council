  1. Go to console.cloud.google.com and create an OAuth 2.0 Client ID (Web Application).
  2. Apply for a Google Ads Developer Token at ads.google.com/intl/en_us/home/tools/manager-accounts/.
  3. Run the OAuth flow to obtain a Refresh Token with scope https://www.googleapis.com/auth/adwords.
  4. Find your Customer ID (10-digit number) in the top-right of your Google Ads dashboard.
